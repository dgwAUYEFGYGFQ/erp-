# 采购云成本管理模块优化建设 PRD Memory

## 需求来源摘要

- 用户要求使用 `chint-prd-iteration` 为既有采购云成本管理模块编写迭代升级 PRD。
- 本次不是新建系统，而是在现有采购云成本模块基础上做优化改造。
- PRD 必须先识别现有系统已有能力，再区分已有功能、优化功能、新增功能和暂不纳入范围。

## 已明确口径

- 正式价和预测价的台账都从采购云核算单审批通过之后同步生成。
- 正式价可关联供应商，采购云审批通过后同步正式价台账并同步 OA 调价单。
- OA 承担正式价调价审批，OA 审批通过后按现有机制同步 SAP 价格库；采购云不直接写 SAP 价格库。
- 预测价不关联供应商，不触发 OA，不同步 SAP。
- 预测价台账和订单测算平台同步字段不包含供应商。
- 供应商价格规则仅用于正式价场景。

## 后续重点待确认

- 正式价多供应商场景下的预实对比口径。
- 偏差率分母和目标绩效达成判定规则。
- 采购云核算单审批节点和审批角色。
- 系统管理员、采购大领导是否可查看全部敏感价格。
- 订单测算平台默认使用的预测版本。
